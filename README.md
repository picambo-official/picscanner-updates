# PicScanner – Downloads und Hilfe

PicScanner von Picambo: Dokumente scannen, bearbeiten und lokal verwalten. Der App-Quellcode bleibt privat.

## Android herunterladen

[PicScanner bei Google Play](https://play.google.com/store/apps/details?id=com.picambo.picscanner)

Neue Android-Versionen und Updates kommen über Google Play. Die öffentliche Store-Version und interne Vorabversionen sind getrennte Kanäle.
