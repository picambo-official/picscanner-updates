# PicScanner 0.8.12 (4030)

Neue Funktionen für die nächste gemeinsame Android- und iOS-Version. Den tatsächlichen Auslieferungsstand zeigt die [Downloadübersicht](../README.md).

- Lokale NAS-Sicherung per FTP mit dauerhaft vorgemerkten Dateien bei fehlender Verbindung. Die Übertragung wird bei erreichbarem Server erneut versucht, auch in vom Betriebssystem freigegebenen Hintergrundläufen.
- FTP ist auf private Netzwerkadressen begrenzt und unverschlüsselt. Für verschlüsselte Übertragung steht HTTPS-WebDAV zur Verfügung. Es handelt sich um eine Sicherung von PicScanner zum Server, nicht um einen beidseitigen Abgleich.
- Original-PDFs ohne dauerhafte Seitenbilder ablegen; vorhandenen Text auslesen und textlose Seiten lokal erkennen. Die Volltextsuche funktioniert weiterhin, die Original-PDF bleibt unverändert. Eine spätere Umwandlung für die Seitenbearbeitung ist möglich.
- Lange Belege auf Bildschirmbreite vergrößern, auch bei sehr schmalen Seiten.
- Schnellere Aufnahmefolge und verbesserte Seitenansicht.
